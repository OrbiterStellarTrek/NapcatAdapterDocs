## 致想要共建本文档的开发者

建议直接使用文档下方的“在 GitHub 上编辑此页”

> [!TIP]
> 本文档集成了一个Tooltip的组件，只需要像使用HTML标签那样使用即可   
> 例如这样   
> ```这是一段文本<Tooltip>这是感叹号内容，跟在“文本”两字后面<tooltip>```


1. 拉取到本地
```console
git clone --depth=1 https://github.com/OrbiterStellarTrek/NapcatAdapterDocs
```

2. 安装依赖
使用pnpm安装依赖
```console
npm i -g pnpm
pnpm i -P
```

3. 本地开发
```console
pnpm docs:dev
```

4. 构建站点
```
pnpm docs:build
```

贡献请使用[PR](https://github.com/OrbiterStellarTrek/NapcatAdapterDocs/compare)

本站已制作自动构建并发布的自动化脚本，您无需构建页面，只需要修改源文件即可
